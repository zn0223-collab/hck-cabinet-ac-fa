# چگونه کولر کابینتی مناسب برای محفظه‌های صنعتی انتخاب کنیم

راهنمای عملی انتخاب برای تابلوهای برق، مخابرات، باتری و کابین‌ها.

وقتی محیط بالای ۴۰°C باشد، فن کافی نیست. **سیستم حلقه بسته** (کمپرسور، IP55) داخل را ۲۵ تا ۳۵°C نگه می‌دارد و گرد و غبار/رطوبت را راه نمی‌دهد.

## اندازه‌گیری
- کوچک (<۲ متر مکعب): **۳۰۰۰ وات**
- متوسط (۲ تا ۴ متر مکعب): **۵۰۰۰ وات**
- بزرگ/کانتینر (>۴ متر مکعب): **۷۵۰۰ وات**

## نکات مهم
- IP55 برای فضای باز و صنعت
- کار **از ۴۰- تا ۵۵+°C**
- R410A + میکروکانال (≈۳۰٪ بازده‌تر)
- RS485/Modbus از راه دور
- از ۵۲ دسی‌بل، بدون ابزار
